# CLAUDE.md — Instructions for Claude Code

## Project overview

`mcsr-kb` is a public knowledge base of Minecraft 1.16.1 game mechanics for speedrunners. Content is generated by analyzing the decompiled source at `./mc1.16.1/` (gitignored) and writing structured Markdown articles.

## Article authoring workflow

1. Identify the relevant Java class(es) in `mc1.16.1/src/` for the mechanic being documented.
2. Read and analyze the relevant methods — focus on conditions, branches, and constants.
3. Write a KB article following the schema in `schemas/article.schema.json`.
4. Register the article in `kb/index.md`.

**Never commit**:
- Raw Java source excerpts or snippets longer than a single method signature
- Anything from `mc1.16.1/`
- Decompiler output in any form

## KB article conventions

### Frontmatter (required)

```yaml
---
title: <descriptive title>
topic: worldgen | entities | rng | physics | mechanics
subtopic: <optional>
tags: [snake_case, keywords]
source_classes:
  - net.minecraft.fully.qualified.ClassName
mc_version: 1.16.1
summary: "<one sentence direct answer — the most important field>"
---
```

### Body structure

Use this section order (omit sections that don't apply):

1. **Overview** — 2–4 sentences expanding the summary
2. **Conditions / Rules** — bulleted list; use plain English, not Java
3. **Step-by-step logic** — numbered list for sequential processes
4. **Constants and values** — table of magic numbers, ranges, probabilities
5. **Edge cases** — unusual inputs or boundary conditions
6. **Speedrun relevance** — what this means for routing or manipulation
7. **Caveats** — obfuscation gaps, unconfirmed behavior, version caveats
8. **Source classes** — prose explanation of which classes to read for more detail

### Style rules

- Describe *behavior*, not code. "The game picks a random angle" not "Math.nextFloat() is called."
- You may name a class to establish credibility: "StrongholdStructure places strongholds in rings."
- Use speedrunning vocabulary: seed, RNG manipulation, cycle, tick, etc.
- Tables for numeric constants (distances, probabilities, counts).
- Bold key terms on first use.

## Adding a new article

```
kb/<topic>/<descriptive-slug>.md
```

Then add a line to `kb/index.md` under the appropriate section:

```
| [Title](./topic/slug.md) | one-sentence summary | stub \| partial \| complete |
```

## Running generation scripts

See `scripts/README.md`. Scripts read from `mc1.16.1/` and write structured output to `kb/`. Always review generated output before committing.

## Schema validation

```bash
# Validate frontmatter against schema (requires ajv-cli)
npx ajv validate -s schemas/article.schema.json -d <(python3 scripts/extract_frontmatter.py kb/worldgen/stronghold.md)
```
